# Pravidla pro projekt listing-hub

## Striktní pravidlo pro soukromý kontext projektu
* **Soukromé zaměření:** Projekt `listing-hub` je výhradně osobní/soukromý projekt uživatele (Ondřej Hála).
* **Zákaz firemních značek:** Je přísně zakázáno vkládat do jakéhokoliv souboru v tomto repozitáři (Dockerfile, Python kód, HTML, dokumentace, Docker labels, metadata) firemní názvy jako `TERMS`, `Roboton` nebo zmínky o rodinných inženýrských tradicích a dotačních programech (STEP).
* **Vystupování a autorství:** V metadatech (autor, vendor) uváděj výhradně jméno `Ondřej Hála`.
