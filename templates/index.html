Aktualizace Docker Kontejneru

Aplikace běží v Docker kontejneru. Kvůli zachování bezpečnosti a neměnnosti (immutability) kontejnerů nelze aktualizaci provést zevnitř aplikace.

Pro ruční aktualizaci spusťte na vašem serveru:

docker compose pull && docker compose up -d

Doporučení: Automatické aktualizace (Watchtower)

Pro plně automatické stahování a aktualizace bez nutnosti ručních zásahů můžete do svého docker-compose.yml přidat Watchtower:

services:
  watchtower:
    image: containrrr/watchtower
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    command: --interval 3600 --cleanup bazos-automat
